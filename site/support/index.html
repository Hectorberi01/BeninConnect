Questions fréquentes

Je n'ai pas reçu le code de vérification

Vérifiez vos courriers indésirables, puis touchez « Renvoyer le code » sur l'écran de vérification. Le code n'est valable que quelques minutes.

J'ai oublié mon mot de passe

Sur l'écran de connexion, touchez « Mot de passe oublié ? » et suivez les instructions reçues par email.

Je ne reçois pas les notifications

Sur iPhone : Réglages › BéninConnect › Notifications, puis autorisez-les. Dans l'application, vérifiez les catégories activées dans Profil › Paramètres › Notifications.

Supprimer une de mes publications

Touchez « ⋯ » en haut de la publication, puis « Supprimer la publication ».

Signaler un contenu ou un membre

Touchez « ⋯ » sur une publication, « Signaler » sous un commentaire, ou le drapeau en haut d'un profil ou d'une communauté, puis choisissez le motif. Notre équipe examine chaque signalement : les contenus contraires aux conditions d'utilisation sont retirés et les comptes concernés peuvent être suspendus.

Supprimer mon compte

Dans l'application : Profil › Paramètres › Supprimer mon compte, puis confirmez avec votre mot de passe. Voir aussi la page Supprimer mon compte.
