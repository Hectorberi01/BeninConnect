Support

Une question, un problème ou une suggestion ? Notre équipe vous répond sous 48 heures ouvrées.

Écrire au support

contact@hbatechettrade.com — précisez l'adresse email de votre compte et le modèle de votre téléphone.

Je n'ai pas reçu le code de vérification

Vérifiez vos courriers indésirables, puis utilisez « Renvoyer le code » sur l'écran de vérification. Le code est valable quelques minutes.

J'ai oublié mon mot de passe

Sur l'écran de connexion, touchez « Mot de passe oublié ? » et suivez les instructions reçues par email.

Je ne reçois pas les notifications

Ouvrez Réglages › BéninConnect › Notifications sur votre iPhone et autorisez-les. Dans l'application, vérifiez les catégories activées dans Paramètres › Notifications.

Signaler un contenu ou un membre

Écrivez-nous en indiquant le contenu ou le profil concerné. Les contenus contraires à nos règles sont retirés et les comptes concernés peuvent être suspendus.

Supprimer mon compte

Envoyez-nous une demande depuis l'adresse email de votre compte. Votre compte et vos données personnelles sont supprimés sous 30 jours.
